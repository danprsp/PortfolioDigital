InvSort: Gerenciador de Estoque

Trabalhei no desenvolvimento do Inv.Sort, uma aplicação de gerenciamento de estoque usando TypeScript e Node.js. Contribuí com a criação da tela de login e o gerenciamento de queries MySQL. O Inv.Sort oferece uma gestão prática e inteligente do inventário, incluindo análise de tendências, cadastro de produtos e controle de entradas e saídas.

API KernelPanic

Este projeto tem como objetivo desenvolver uma API para análise de dados das exportações e importações do estado de São Paulo. A solução permitirá a extração e visualização de informações estratégicas sobre os produtos exportados, destinos e tendências históricas. Como Scrum Master, sou responsável por organizar as reuniões diárias, remover impedimentos, facilitar a comunicação da equipe e garantir as práticas do Scrum. Também participo no desenvolvimento com Flask para criação de endpoints.
